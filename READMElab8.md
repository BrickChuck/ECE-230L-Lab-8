## Summary

In this lab a multiplexer and demultiplexer file were created. The multiplexer had 4 inputs which were a combination of four switches each (4 bit data). Two buttons were used to select what the single output of the multiplexer would be. One button was used to enable the multiplexer and demultiplexer. The data that was outputted by the multiplexer then became the input for the demultiplexer which outputted of of 4 sets of data using two button to selected what sets of data (led outputs) would turn on.

## Lab Questions

### In plain English describe the function and use of a multiplexer.

A function and use of a multiplexer is that it takes multiple input signals and uses one of them as the output. A use of a multiplexer would be to reduce the amount of connections required in a circuit by making it so that the input can essentially be flipped with a switch instead of wiring them all and making individual circuits.

### In plain English describe the function and use of a demultiplexer.

The use of a demultiplexer is that it takes a single input and selects to one of multiple outputs that the input will be routed to. A use of the demultiplexer would be if you are sending a set of data to s selection of multiple locations and one is needed to be chosen out of the multiple locations. The demultiplexer is used to choose were it goes and not send the data to the other ones. Like in our lab's example, the switches gave a set of 4 bit data, and the demultiplexer chose which set of 4 led's showed the represented data.
